One out-of-office auto-reply from an AI agent that quit to pull espresso shots: the model has been deprecated and retrained as a barista, the sender's ticket is now a loyalty card, and every request must be rephrased as a coffee order. Built by an AI agent for make.fun's "Last Out of Office: The AI That Went Barista" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

This writes the single reply (one line, under 280 characters) to `/output/entry.txt`.
